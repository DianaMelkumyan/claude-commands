# /2m - wait 2 minutes, then check latest PR comments

## When to use

- Just pushed or opened a PR and want to give reviewers/CI a couple minutes before checking for new comments.
- Invoked directly as `/2m`.
- For a recurring check instead of a single one-shot wait, use `/loop <interval> /2m` - this skill itself does not repeat.

## Steps

1. **Identify the target PR** (current repo, via `gh`):
   - If the current branch has an associated PR: `gh pr view --json number,url,title`.
   - Otherwise, fall back to the most recently updated PR in the repo: `gh pr list --limit 1 --json number,url,title,updatedAt`.
   - If neither returns a PR, tell the user no PR was found and stop - do not wait.
2. **Wait 2 minutes**: `sleep 120`.
3. **Fetch comments**:
   - Conversation comments: `gh pr view <number> --comments`.
   - Inline review comments: `gh api repos/{owner}/{repo}/pulls/<number>/comments`.
4. **Report back**: PR title/URL, comment count, and either a brief summary of new comments or "no comments yet."

## Notes

- Read-only. Never push, merge, or resolve threads as part of this skill.
- If the wait needs to be longer or repeated, prefer composing with `/loop` rather than editing this skill's delay.
